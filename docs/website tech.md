Website design principles:
- Minimize time from first http get to browser-ready for Dutch users: fastest network transfer, smallest artifacts, fast rendering
- No GDPR banners: no (or only essential cookies), local fonts/scripts, no analytics
- Free hosting:
    - Ability to serve https://fristlinesoftware.nl
    - Keep current EuroDNS provider (potentially with DNSSEC)
    - Ok with public repository
    - it should not be developed using personal credentials, at the end of the day it has to be within FLS corp account and IT team should be able to maintain it
