# NL translation styleguide

For the future automated EN → NL translation step to follow. Pulled from
`_meta/OFFERING.md` §2 and the existing live copy — not yet enforced by tooling.

- Register: informal "je" (never "u"), consistent with nl.firstlinesoftware.com.
- Never brand this as cost-cutting; frame is optimize-to-fund-AI.
- No sysadmin/manual-instruction tone — the scan hands out a mirror and questions,
  not step-by-step portal manuals. Link Microsoft docs instead of restating them.
- Keep sentences short and concrete; prefer a specific number/example over an
  abstract claim (e.g. "six machines named *test* ran every night" beats
  "unused resources were found").
- Preserve product/technical terms as-is (Azure, CSV, WebAssembly, portal.azure.com,
  Cost Management + Billing) — do not translate proper nouns or UI labels that refer
  to the actual Microsoft product.
